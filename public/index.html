🌌 Code Galaxy - מרכז המידע

1. הקסם מאחורי הקלעים: מיפוי וארכיטקטורה

Code Galaxy אינה סתם עורך קוד – היא מנוע ויזואליזציה. כאשר פרויקט נטען, המערכת סורקת את הקוד ומפענחת אותו (AST) כדי לזהות פונקציות, מחלקות וקשרי ייבוא (Imports). לאחר מכן, היא משתמשת במודל הוקטורים של גוגל (Gemini Embeddings) כדי להבין את המשמעות הלוגית של הקוד, ומייצרת גלקסיה תלת-ממדית שבה קבצים קשורים נמשכים זה לזה באמצעות קווים סמנטיים (סגולים) ומבניים (כחולים).

2. סינון חכם לביצועי שיא

כדי להבטיח שהגלקסיה שלך תעבוד בצורה חלקה וללא תקיעות, המערכת מפעילה סינון קפדני:

  • שפות נתמכות: המערכת מזהה ומנתחת שפות רבות, ביניהן: JS, TS, Python, Java, C#, C++, Go, Dart, HTML, CSS, JSON.
  • השמטות אוטומטיות: ספריות צד-שלישי, תיקיות בנייה וקובצי תצורה כבדים (כגון node_modules, .git, dist, build, data, package-lock.json) מסוננים אוטומטית החוצה.
  • מגבלת גודל: קבצים השוקלים מעל 500KB מושמטים אוטומטית כדי לשמור על ביצועי ה-AI וזמני הטעינה.

3. המוח של המערכת: עוזר ה-AI שלך

המערכת מצוידת בעוזר וירטואלי חכם תלוי-הקשר (Context-Aware), הפועל בשני מצבים:

  • הצ'אט הגלובלי: פועל כאשר אינך ממוקד בקובץ ספציפי. הוא רואה את הפרויקט בשלמותו (RAG), מבין את הארכיטקטורה, ויודע לענות על שאלות רוחביות (למשל: "איך עובד מנגנון ההזדהות בפרויקט?").
  • הצ'אט המקומי: כאשר תלחץ על קובץ ספציפי, העוזר יתמקד בו. כאן תוכל לבקש שיפורי קוד (Refactor), הסברים נקודתיים, ואפילו להשתמש במנגנון ה-Smart Split שמפצל אוטומטית קבצים ארוכים ומייצר "כוכבים" חדשים בגלקסיה.

4. סביבת עבודה בטוחה (Safe Workspace & Diff)

הקוד המקורי שלך בטוח לחלוטין. כאשר ה-AI מציע שינוי, תיקון או פיצול קובץ, הפעולה לא נשמרת מיד בדיסק המקומי. המערכת מציגה לך תחילה תצוגה מקדימה מפורטת בעורך הימני, הכוללת מנגנון השוואה (Diff) המדגיש באדום את הקוד שיוסר ובירוק את הקוד שיתווסף. רק לאחר שתאשר את הפעולה ותלחץ על "החל שינויים", המערכת תעדכן את הקובץ המקורי במחשב שלך.

5. פרטיות, מטמון וניהול משאבים

  • עיבוד מקומי ומטמון (Cache): נתוני הניתוח של הקוד נשמרים מקומית במנגנון מטמון חכם. טעינה חוזרת של פרויקט שכבר נותח תתרחש בשבריר שנייה מבלי לפנות שוב לשרת או ל-API.
  • פרויקטים מ-GitHub: פרויקטים מיובאים עוברים שיבוט (Clone) לזיכרון המקומי לטובת הניתוח. ברגע שתמחק פרויקט מרשימת "היסטוריית הפרויקטים", הוא יושמד לחלוטין מהשרת המקומי.

6. הצהרת אחריות (Disclaimer)

Code Galaxy נועדה לשמש ככלי עזר מתקדם למפתחים ולספק המלצות קוד מבוססות בינה מלאכותית. עם זאת, עוזרי AI עשויים לייצר לעיתים קוד שגוי או לא מאובטח. האחריות הבלעדית על בדיקת הקוד, בחינת התאימות שלו, והטמעתו הסופית בפרויקט המקורי חלה על המשתמש בלבד.
